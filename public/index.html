NIST PQC Migration Roadmap

Recommended post-quantum replacements aligned with FIPS 203 / 204 standards.

🔑

Digital Signatures

RSA-2048 / ECDSA
ML-DSA (Dilithium)
FIPS 204

Lattice-based digital signature scheme. Drop-in replacement for RSA and ECDSA signing operations.

🔄

Key Exchange

ECDH (P-256)
ML-KEM (Kyber)
FIPS 203

Lattice-based key encapsulation mechanism. Replaces ECDH for secure key agreement.

🛡️

SaaS / Okta SSO

RS256 / ES256 JWKS
Hybrid RSA + ML-DSA
Pending IdP Support

Adopt hybrid signatures during transition. Monitor Okta's PQC roadmap for SDK updates.

🔒

Symmetric & Hashing

AES-256 / SHA-256
AES-256 / SHA-384+
Already Sufficient

AES-256 retains 128-bit quantum security. Upgrade hashing to SHA-384/512 for additional margin.

Phase 1 — Hybrid Mode

Now → 2027

Deploy hybrid signatures (RSA + ML-DSA) and hybrid key exchange (ECDH + ML-KEM) for backward compatibility with quantum resistance.

Phase 2 — PQC-Only

2027 → 2030

Deprecate classical algorithms. Transition all signing to ML-DSA and all key exchange to ML-KEM as ecosystem support matures.

Phase 3 — Full Compliance

2030+

Complete migration to NIST PQC standards. Remove all classical crypto dependencies. Achieve full quantum readiness certification.
